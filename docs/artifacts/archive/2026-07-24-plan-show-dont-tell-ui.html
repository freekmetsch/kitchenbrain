Hard guardrails

The visual layer may reveal the model. It may not rewrite the model by accident.

One source helper

Fresh and freezer defaults are computed once and tested through both callers.

No false shopping merge

Grouping is presentational; exact rows, entry IDs, and bought state remain canonical.

Dutch stays canonical

Shopping and AH continue to read Dutch ingredient terms only.

No LLM URLs

Assistant actions use typed entity metadata and app-derived, allowlisted local routes.

No reset-all

Import blockers link to existing per-group, type-to-confirm controls.

No fake preview

Async cooking regeneration must show its real Preparing/Refreshing state.

Proof before deploy

All writes use a copied database. Provider and AH stories use fixtures. The real household plan and basket stay untouched.
