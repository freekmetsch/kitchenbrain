Deployment stage

How late is still useful?

The current 60-second TTL and stale grace permanently drop alerts after a short sleep or connectivity gap. An overly long window creates confusing stale alarms.

Late-delivery window

When should native Android start?

Capacitor Local Notifications can schedule on-device, but this adapter-node app needs a real bundled client/API boundary, exact-alarm permission handling, signing, and update ownership.
