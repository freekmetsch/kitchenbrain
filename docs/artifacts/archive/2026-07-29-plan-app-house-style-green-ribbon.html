Risk and recovery

This is a wide presentation sweep, but its rollback is intentionally boring: code commits and one feature-PR revert.

R2, no stage gate

Shared primitives and every stable route change. Schema, auth, secrets, runtime config, providers, AH behavior, and persisted data do not.

  • Opt-in kitchen tokens prevent bleed into excluded surfaces.
  • Route tests preserve behavior while geometry changes.
  • No new dependency or service enters the stack.

Rollback path

Before merge, revert tickets in reverse dependency order. After merge, revert the whole feature PR and supervise the resulting Railway deployment.

  • No database down migration.
  • No auth, secret, token, volume, or config recovery.
  • No retained authenticated screenshot or response body.
