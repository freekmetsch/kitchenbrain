Direction Main strength Main trade-off Behavior it optimizes Scope signal
A1 · Quiet Ledger Most items per screen; filters and sorting stay visible without becoming the page. Meal discovery relies on compact chips instead of visual cards. Open list, scan, check, continue. Uses current item and meal-source data.
A2 · Meal Lens Turns the old Meals intent into a clear filter rather than a different settings screen. The meal rail delays the first item and can feel too plan-oriented in store. Pick a meal, then see exactly what remains for it. Uses current data; higher UI composition cost.
A3 · Store Route Best physical shopping sequence and clearest structure for a long list. Wrong classifications create friction and need a correction path. Finish one shop section before moving to the next. Requires a new category source and ownership decision.
