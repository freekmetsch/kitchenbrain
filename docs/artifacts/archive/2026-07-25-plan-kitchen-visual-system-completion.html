Zero count: honest status replaces button affordance.
Active: pressed state, result count, and clear path remain visible.

Market Run

Empty: Plan meals starts the journey.
Complete: basket result replaces run urgency.
AH offline/stale: status and recovery remain in context.
Sending/uncertain: locked and no-retry outcomes stay explicit.

Meal Plan

Empty: Add meal owns the next action.
Long: meal and note content expands the ledger row.
Pending: edit/serving controls show local busy state.
Suggestion failure: valid context remains with retry.
