Remove the shortcuts. Keep the invitation to start.

Three structurally different ways to make contextual sentence starters calmer after the Open / Shopping list / Meal plan row disappears.

Already decided

  • No empty-state navigation shortcut row.
  • Starters remain contextual and never send on selection.
  • Hide and restore use explicit text.
  • The same component serves the Assistant tab and page panel.

Choose the presentation

All three examples use the same copy, widths, composer, and empty state. Select the balance of recognition and density you want to carry into planning.
