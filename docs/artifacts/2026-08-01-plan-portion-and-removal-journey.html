What is actually broken

The browser audit established the visible friction. Controller and storage traces established the underlying causes.

P1

Recipe input is blocked by guidance loading

Every Recipe serving button is disabled during an unrelated structured-cooking request. Slow or failed guidance makes local arithmetic inaccessible.

P1

Recipe never writes the planned meal

Even with an exact plan ID, the current control changes only local cook-session storage, so Shopping and Meal Plan cannot follow it.

P1

Fast Meal Plan input disappears

A pending-request guard discards repeated taps, while source changes can write the same serving field through another path.

P1

Shopping has no safe meal control

It keeps ingredient-source names, not editable meal records. Controls belong on one row per planned meal, never on repeated aggregate ingredients.

Delivery map
