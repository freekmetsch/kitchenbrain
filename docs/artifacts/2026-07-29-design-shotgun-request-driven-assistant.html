Before an effectShow evidence, uncertainty, consequence, and alternatives. Writes and AH pushes remain reviewed.

02 · Guardrails

What “assertive” means here

Initiative belongs inside the user’s request. Authority still stops at state changes and external consequences.

Don’t ask to lookRead the relevant household facts and compare options as implied work.
Don’t narrate toolsOne honest working state is enough; return the prepared outcome, not a process diary.
Don’t presume tasteRecommend a default from evidence, expose uncertainty, and keep alternatives easy to select.
Don’t cross the gateLocal writes, destructive actions, purchases, and AH push remain explicit reviews.
