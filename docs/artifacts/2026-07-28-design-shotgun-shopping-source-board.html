Recommendation

Start with Source Ledger.

It honors the Source Board decision without making a long shopping run feel like a dashboard.

Weekly still leads

Recurring items own the first section and their single Manage action.

Shared stays honest

Recipe-only shared items appear once, with every source named on the row.

No order UI

The board always follows stable List order. There is no dropdown or hidden alternative.

Less framing

Source bands provide hierarchy with fewer borders, shadows, and repeated card margins.

Decision workspace

Choose the board’s final behavior

Selections and notes stay in this browser. Untouched, the workspace accepts every recommendation.
